The handful of technical words this page uses, in one sentence each
ASP
Agentic Service Provider — a tool OKX.AI's agent marketplace lists for other agents to call.
MCP
Model Context Protocol — the standard AI agents use to discover and call tools like KARMA's.
A2MCP
Agent-to-MCP — one agent calling another agent's MCP-exposed service, machine to machine.
ERC-8004
The identity standard OKX.AI's own Onchain OS uses for agent User/ASP/Evaluator roles.
Aggregate score
A plain average of whatever chains actually returned a reputation — never a fabricated number for an unconfigured chain.
Rationale attestation
An on-chain hash of an agent's stated reason for a decision — checkable, but the plaintext never has to leave the agent.

Rationale attestation (P2-A) — ported from Casper, X Layer's turn next
